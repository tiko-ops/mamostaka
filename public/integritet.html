Integritet

Mamosta är byggt för att samla in så lite som möjligt. Här är det korta svaret på vad som händer med din text.

Din text

  • Texten skickas krypterat (HTTPS) till vår server och vidare till vår AI-leverantör OpenAI, som gör själva rättningen.
  • Mamosta sparar inte texten och loggar den inte. När du stänger eller rensar sidan finns den inte kvar hos oss.
  • OpenAI använder inte texter som skickas via deras API för att träna sina modeller.
  • När du ber om förklaringar skickas bara de ändrade orden och några ord runt dem.

Cookies och spårning

Vi använder inga cookies, ingen analys och inga spårningsskript. Vi behöver inget konto eller några personuppgifter från dig.

För att stoppa missbruk räknar servern hur många rättningar som görs från varje IP-adress under tio minuter. IP-adressen finns bara tillfälligt i serverns minne och sparas eller loggas inte.

Om du väljer ett språk för förklaringarna kommer webbläsaren ihåg ditt val (i localStorage). Det stannar på din enhet och skickas aldrig till oss.

Tips

Undvik att klistra in känsliga uppgifter som personnummer, lösenord eller hälsouppgifter.
